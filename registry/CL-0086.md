# CL-0086 — The Warm Bulb
Status: SCRIPTED (IDEA -> VALIDATED -> SCRIPTED, 2026-11-07, registered BEFORE production)
Created: 2026-11-07 · Category: Think like a detective · Language: English
Suspects: Sal, Tia, Uri
Evidence per suspect: Sal: on for ten minutes, then off | Tia: switched on, left on | Uri: never touched
Clues (board): 3 SWITCHES IN THE HALL · 1 BULB INSIDE THE VAULT · ONE VISIT ONLY
Solution: Sal
Mechanism (do not reuse): Heat memory of an incandescent bulb: on-then-off leaves it warm and dark; currently on is lit; never touched is cold.
Script (EN): Three switches. One bulb. One visit. And the answer is hiding in the heat. A vault has three switches in the hall, and one bulb inside. You can enter the vault only once. Sal runs the first switch, Tia runs the second, Uri runs the third. Sal's switch is left on for ten minutes, then turned off. Tia's switch is turned on, and left on. Uri's switch is never touched. You step inside. The bulb is dark, but warm. Whose switch controls the light? You have five seconds. Five. Four. Three. Two. One. It was Sal. A bulb that burned for ten minutes grows hot, and stays warm after it goes dark. If it were Tia's, it would shine. If it were Uri's, it would be cold. Warm and dark means Sal's switch.
