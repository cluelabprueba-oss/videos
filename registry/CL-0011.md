# CL-0011 — The Misspelled Threat
Status: VALIDATED
Created: 2026-11-15 (batch run 2026-11-14 UTC) · Category: Hidden clue · Language: English
Setting: Ashby Theatre. The lead actress receives a threatening letter.
Suspects:
- VERA (Understudy): Gets the lead if the star quits. Writes with the same red ink as the letter.
- NOEL (Director): Statement: "I will definitely cooperate."
- PIP (Stagehand): Statement: "I definately saw nothing."
Clues:
1) The letter: "You will DEFINATELY regret it"
2) Red ink is sold at every shop in town
3) Each suspect wrote a short statement
Solution: Pip. The letter misspells 'definitely' as 'definately', and Pip's statement makes exactly the same mistake. Red ink is common: Vera's pen proves nothing. Noel spells it correctly.
Mechanism (do not reuse): Matching handwriting-independent spelling error between anonymous note and statement.
